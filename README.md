# Integers

Operator-algebraic research publications by G Six, San Francisco CA, 2026.

## Published artifacts

### Tomita-Takesaki uniqueness in the Bost-Connes system

Formalization of a Theorem C closure result for the Bost-Connes
algebra at the critical line β=1, via Takesaki's KMS-uniqueness
theorem. Unconditional in Lean with 8 named-literature axioms.

- Paper: [localparty/tt-bost-connes](https://github.com/localparty/tt-bost-connes)
- Lean formalization: [localparty/tt-bost-connes-lean](https://github.com/localparty/tt-bost-connes-lean)

### The Bost-Connes Modular Generator as a candidate Hilbert-Pólya Operator

Transparent reduction of the Riemann Hypothesis to a single concrete type-inhabitation problem in Lean 4, built from the Bost-Connes type III_1 factor's modular data plus a Galerkin approximation chain. **Not an unconditional closure of RH** — a conditional scaffold over a named gate that is equivalent to RH.

- Paper: [localparty/hilbert-polya-bost-connes](https://github.com/localparty/hilbert-polya-bost-connes) (DOI [10.5281/zenodo.20916427](https://doi.org/10.5281/zenodo.20916427))
- Lean formalization: [localparty/hilbert-polya-bost-connes-lean](https://github.com/localparty/hilbert-polya-bost-connes-lean) (DOI [10.5281/zenodo.20916336](https://doi.org/10.5281/zenodo.20916336))
