### Tomita-Takesaki uniqueness in the Bost-Connes system

Formalization of a Theorem C closure result for the Bost-Connes
algebra at the critical line β=1, via Takesaki's KMS-uniqueness
theorem. Unconditional in Lean with 8 named-literature axioms.

- Paper: [localparty/tt-bost-connes](https://github.com/localparty/tt-bost-connes)
- Lean formalization: [localparty/tt-bost-connes-lean](https://github.com/localparty/tt-bost-connes-lean)
